# MySkills — научные навыки и практикум для Codex

Коллекция рабочих методов Романа Рыльцева по вычислительному материаловедению. Здесь собраны 16 навыков Codex, скрипты из исследовательских проектов, исходные рецепты расчётов и русскоязычные задания. Начать можно с обычного Python на ноутбуке. GPU, кластер и лицензированные программы понадобятся на тех занятиях, где вы захотите повторить сам расчёт.

## Начать на другой машине

Установите Git и Python 3.9 или новее для установщика. Откройте терминал в каталоге, где будет постоянно храниться коллекция. В Windows при необходимости замените `python` на `py -3`, в Linux/macOS — на `python3`.

```sh
git clone https://github.com/rryltsev/MySkills.git
cd MySkills
python tools/install.py --list
python tools/install.py
python tools/install.py --check
python lessons/first_run.py
```

Установщик копирует навыки в пользовательский каталог `~/.agents/skills`. Код, учебник и исторические рецепты остаются в клоне. Каждая установленная копия содержит указатель на его расположение. По итогам проверки у всех выбранных навыков должно стоять `current`. Учебный пример выдаёт поправку −0,050 эВ/атом, параметр Уоррена–Каули +0,50 и энтальпию смешения −0,100 эВ/атом. [Установка в отдельный проект, обновления и устранение проблем](lessons/installation.md).

Откройте каталог MySkills в Codex и начните новый чат. Первый запрос можно вставить целиком:

> Пройди со мной первый урок из lessons/course.md. Проверь установку и запусти lessons/first_run.py. Предложи мне сначала предсказать знак параметра Уоррена–Каули, затем проверь мой ответ по коду. Пусть следующая задача зависит от моей ошибки. Работаем локально.

## Что изучать

| Цель | С чего начать | Что получите |
| --- | --- | --- |
| Освоить коллекцию с нуля | [Программа занятий](lessons/course.md) | Для каждого из 16 навыков есть задача и признак правильного решения |
| Найти подходящий навык | [Каталог с точками входа](lessons/catalog.md) | Точное имя для запроса Codex, входные данные и получаемый результат |
| Освоить путь DFT → MLIP → молекулярная динамика | [Справочник, шаблоны и исходные рецепты](toolkit/README.md) | Подготовка расчёта, обучение и путь до проверяемого физического свойства |
| Проверить замороженный DPA4 | [Практикум экспорта](methods/deployment/README.md) | Проверка энергии, сил и напряжения на одних и тех же кадрах |
| Построить термодинамику сплава | [Практикум по сплавам](methods/alloys/README.md) | ATAT, кластерное разложение, MFA, VC-SGC и атомистическая свободная энергия |
| Разобрать исследовательские случаи | [Проектные практикумы](methods/projects/README.md) | GFA, ближний порядок, вязкость оксидов, слепая символьная регрессия, QHA и проверки потенциалов |
| Выяснить происхождение и пределы воспроизведения | [Карта источников](lessons/sources.md) | Где лежит реализация, что проверялось локально и какие исходные данные нужны |

**Два правила рабочих расчётов.** Для многократного вывода DPA4 применяйте проверенный `.pt2`, экспортированный при `DP_TRITON_INFER=2`. Проверяйте энергию, силы и напряжения и записывайте, какой файл реально прочитал исполнитель. Для каждой новой серии UMT пользователь выбирает учётную запись до запуска. Постоянные правила удобно перенести также в личный `AGENTS.md` новой машины. [Инструкция](lessons/installation.md).
