# Установка, перенос и обновление

## Сначала с изолированной установкой

В каталоге MySkills команда ниже устанавливает два навыка в отдельный учебный проект. Параметр `--dest` задаёт каталог, **внутри которого** появятся папки навыков. Относительные пути отсчитываются от текущего каталога терминала.

```sh
python tools/install.py --dest ../study/.agents/skills lammps liquid-properties
python tools/install.py --dest ../study/.agents/skills --check lammps liquid-properties
```

Откройте `study` в Codex и начните новый чат. Введите: «Используй $lammps. Покажи путь к загруженному SKILL.md, открой его ссылку на RDF/Cowley, объясни, как отличить центры бинов от правых границ». Ответ должен сослаться на установленный навык и реальный файл `references/rdf-cowley-analysis.md`. Для занятий, использующих соседние навыки, установите всю коллекцию. Codex использует каталоги навыков на уровне проекта и пользователя. [Справка OpenAI](https://developers.openai.com/codex/skills/).

## Для всех проектов текущего пользователя

```sh
python tools/install.py
python tools/install.py --check
```

Python 3.9+ и стандартной библиотеки достаточно для установки. Пакеты анализа ставятся отдельно по инструкции выбранного практикума. В учебной копии и при установке `tools/install.py` не подключается к UMT. Старые ZIP-комплекты распаковывать не требуется.

Если имя навыка уже занято вашей собственной копией, установщик выдаст `conflict` и остановится до копирования. Можно изучать коллекцию в отдельном проекте, сравнить две версии через `git diff --no-index путь1 путь2` и осознанно объединить полезные изменения. При `missing` в режиме проверки установите соответствующий навык. При `changed` проверьте изменения и примените обновление ниже. На машине с несколькими пользовательскими каталогами навыков смотрите путь к фактически загруженному `SKILL.md`.

## Обновление и перемещение клона

```sh
git pull --ff-only
python tools/install.py --update
python tools/install.py --check
```

При обновлении изменившейся управляемой копии скрипт сохраняет предыдущую папку в `myskills-backups` рядом с каталогом `skills` и печатает точный путь. Идентичные файлы пропускает. Если вы перенесли клон, выполните те же две команды установщика из нового места. Для установки через `--dest` повторяйте тот же параметр при обновлении и проверке. Чтобы вернуться к накопленным локальным правкам, сравните рабочий навык с напечатанным резервным каталогом.

## Личные правила на новой машине

Добавьте в существующий личный `~/.codex/AGENTS.md` следующий текст с вашими актуальными именами учётных записей и SSH-псевдонимами. Сохраните остальные указания в этом файле. Репозиторий содержит алгоритм выбора, конкретные имена можно хранить в личной конфигурации.

> Для каждого нового расчёта или серии на UMT спроси меня, какую из моих учётных записей использовать, если я уже не указал её для этой серии. Применяй выбранную запись до конца серии. Предыдущий запуск и профиль проекта не задают выбор. SSH-логин и Slurm Account проверяются отдельно.
>
> Для повторной оценки, фононов и МД на DPA4 используй проверенный frozen .pt2. Установи DP_TRITON_INFER=2 во время freeze и убедись, что оценка действительно открыла этот файл. Сверь энергию, силы и напряжения с исходным checkpoint на идентичных структурах. Сохрани .pt для обучения, рестарта и явных эталонных проверок. При ошибке экспорта или валидации остановись и выясни причину. Подробности в навыке mlip-deployment.

Для действительного расчёта дополнительно перенесите доступ к GitHub/SSH обычными средствами вашей машины, получите лицензированные программы через свой канал и заполните профиль проекта. Для локального учебного курса достаточно команд из README. [Указания AGENTS.md в Codex](https://developers.openai.com/codex/guides/agents-md/).
