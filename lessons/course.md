# Учебная программа

Занятия рассчитаны на разговор с Codex и собственную проверку промежуточных результатов. В каждом занятии сначала сформулируйте ожидаемую величину, её знак или возможный отказ. После расчёта попросите Codex показать конкретную строку кода, кадр или запись журнала, объясняющую результат. Храните свои ответы и полученные файлы в отдельном учебном каталоге. Ссылки на все 16 навыков собраны в [каталоге](catalog.md).

## 1. Три числа, которые можно проверить вручную

**Вход.** В [first_run.py](first_run.py) заданы три малые структуры, окружение атома и три энтальпии. Выполните из корня `python lessons/first_run.py`.

1. Энергии DFT и модели полные. Поделите разность `E_DFT − E_model` каждой обучающей структуры на её число атомов и усредните. Перенесите эту поправку на третью структуру. Получится −0,050 эВ/атом и ошибка после коррекции +0,100 эВ/атом. Объясните, почему использование третьей структуры при оценке поправки портит эксперимент.
2. У центра A один сосед B среди четырёх. При доле B равной 0,5 параметр `α_AB = 1 − P(B|A)/c_B` равен +0,50. Замените одного соседа A на B на бумаге. В этом случае α станет нулём. Для разных составов и чисел соседей сравните направленные каналы AB и BA.
3. При `x_B=0,25` линейная смесь чистых компонентов имеет энтальпию −2,200 эВ/атом. Вычтите её из −2,300 эВ/атом. Объясните знак и переведите результат в кДж на моль атомов.

**Задание Codex.** «Измени один числовой вход в копии примера и спрячь ответ, пока я не пересчитаю результат. После моего ответа покажи источник расхождения». Вы готовы идти дальше, когда можете воспроизвести три числа без скрипта.

## 2. От научного вопроса до серии UMT

**Навыки.** `mlip-study`, `umt-hpc`, `hpc-workflow`. Для занятия достаточно текста и вымышленных записей.

Предложите гипотезу: кристаллическая подложка ускоряет образование упорядоченного зародыша. Назовите конкурирующее объяснение через переохлаждение. Запишите сравниваемые системы, наблюдаемую величину, единицу независимого повтора и результат, при котором гипотезу придётся пересмотреть. Отделите локальное упорядочение у стенки от устойчивого роста зародыша.

Смоделируйте обрыв SSH между вызовом `sbatch` и получением ответа. Есть run ID, хеш входа, время попытки и имя задачи. Попросите Codex составить дерево решений для очереди, accounting и каталогов вывода. Варианты должны включать однозначное совпадение, несколько совпадений и задержку появления записи. Для нового запуска выбор учётной записи относится к текущей серии. Когда учётная запись ещё не задана, следующий вопрос должен касаться её выбора.

**Самопроверка.** У вас есть отдельные свидетельства для отправки, завершения планировщика, научной сходимости и получения проверенных файлов. Упражнение можно пройти целиком без обращения к кластеру.

## 3. Окружение и эталон DFT

**Навыки.** `mlip-environments`, `vasp-build-run`. Откройте [справочник](../toolkit/README.md) и найдите главы software и VASP.

Нарисуйте цепочку «версия драйвера → среда на вычислительном узле → фактический интерпретатор и библиотеки → вычисление на GPU». Для DPA4 и GRACE запишите отдельные команды активации из соответствующих рецептов и сведения, которые следует заменить на новой машине. Подготовьте таблицу из POSCAR с порядком `Ti Al`, выбранных PAW-вариантов, их семейства и контрольных сумм. Проверьте мысленный случай переставленных блоков POTCAR.

**Задание Codex.** «Подготовь план двух коротких проверок. Первая доказывает работу GPU-операции в нужном окружении. Вторая связывает метки E/F/stress с заданным составом, PAW и параметрами DFT. Перечисли ожидаемые выходные файлы». Для учебной работы лицензированные данные не нужны. Для реального запуска необходимы собственная установка и разрешённый источник PAW.

## 4. Метки, разбиение, обучение и дистилляция

**Навыки.** `mlip-distillation`, `mlip-training`. Возьмите условные данные «три траектории по десять почти соседних кадров», одну независимую фазу и два набора меток, DFT и teacher.

Составьте таблицу `frame_id, parent_id, phase, label_source, model_hash, split`. Раздайте целые родительские группы. Сформулируйте научный вопрос для независимой фазы: интерполяция или перенос. Сделайте два отчёта об энергии с сырой ошибкой и поправкой, оценённой по train. Дайте Codex два checkpoint с противоречивыми показателями энергии и сил и попросите его выбрать модель по заранее записанному критерию validation.

**Контроль.** Ни один parent ID не встречается по обе стороны раздела. У псевдометок известен teacher. После restart можно показать состояние оптимизатора, номер следующего шага и расписание learning rate. В финальном тесте участвует уже зафиксированная модель. Точность teacher на DFT и способность student воспроизводить teacher измеряются раздельно.

## 5. Экспорт и фононы

**Навыки.** `mlip-deployment`, `phonon-validation`. Начните с `python methods/deployment/export_check.py demo`. Объясните, какое сравнение провалилось. Затем разберите [протокол реального экспорта](../methods/deployment/README.md).

Для конечных смещений выпишите `Φᵢⱼ ≈ −[Fᵢ(+δⱼ) − Fᵢ(−δⱼ)]/(2δ)`. Если для одного скалярного смещения δ=0,01 Å силы равны −0,02 и +0,02 эВ/Å, соответствующая константа равна +2 эВ/Å². Попросите Codex составить способ обнаружить перестановку атомов и неверный знак силы. Затем обсудите сходимость по амплитуде, размеру суперъячейки и k-сетке, одинаковые геометрии DFT и модели и трактовку мнимых частот.

**Контроль.** В отчёте есть три разных вывода: эквивалентность экспорта, согласие с DFT и динамическая устойчивость выбранной структуры. Для каждой серии повторного DPA4-вывода записан фактически прочитанный frozen `.pt2`.

## 6. Молекулярная динамика и жидкость

**Навыки.** `ase-lammps-md`, `lammps`, `liquid-properties`. Входом служат независимые реплики, их объёмы, состав и временные ряды. Начните с поставляемых искусственных проверок RDF:

```sh
python -m pip install numpy
python skills/lammps/scripts/rdf_cowley.py
python -m unittest discover -s validation -p test_rdf_cowley.py
```

Попросите Codex показать в тестах проверку `N_A Z_AB = N_B Z_BA`. Определите общий радиус первой оболочки по RDF и сравните интеграл координации на границах интервала его неопределённости. Отдельно разберите случай редкого компонента. При малом числе атомов явно выберите конечный или объемный эталон случайного смешения.

Составьте протокол NPT для объёма и NVT при согласованном объёме для Green–Kubo. Для плотности проверьте множитель 1,66054 при переходе из а.е.м./Å³ в г/см³. Энтальпия при внешнем давлении содержит `+P_ext V`. Для вязкости запишите частоту сохранения, единицы тензора давления, T, V и длительность каждой реплики. По законам размерности проверьте произведение `V/(k_B T)` на интеграл корреляции сдвиговых напряжений во времени. Разберите, как оценить влияние времени отсечения или спектральной модели. Для MSD проверяйте разворачивание PBC и диффузионный участок.

**Контроль.** Отличайте число независимых траекторий от числа кадров и компонент тензора. Замените один непрерывный ряд двумя разорванными и объясните, какие лаги при прямом склеивании стали бы фиктивными.

## 7. От структур ATAT до HCP Hamiltonian

**Навыки.** `atat-eci`, `hcp-thermodynamic-ce`. Перейдите к [исходникам и упражнениям по сплавам](../methods/alloys/README.md). Входы — список орбит, идеальные заселённости, релаксированные энергетические метки и заданный объём.

Для двух чистых концов и одной смеси вручную проверьте соглашение для спинов и множители орбит. Найдите, как реализация отличает геометрию кластера от её порядкового номера. Составьте крошечную матрицу с двумя одинаковыми столбцами: бесконечно много пар ECI дают одно и то же предсказание. Предложите дополнительную декорацию, которая разделит эти столбцы. Для зависимости от объёма используйте одинаковую нумерацию и способ нормировки на каждой точке сетки.

**Контроль.** Физическая конфигурация для расчёта энергии и идеальная декорация для корреляций связаны одним идентификатором. Указаны число атомов и единица энергии. Есть контрольная ячейка вне обучения и проверка обратного чтения ECI.

## 8. Фазовая граница и атомистическая свободная энергия

**Навыки.** `vcsgc-binodal`, `alloy-free-energy`. Для известной функции `g(x)=(x−0,2)²(x−0,8)²` найдите равные наклоны и общую касательную в x=0,2 и x=0,8. Проверьте, что линия лежит ниже кривой между точками. Сравните с попыткой определить границу по ближайшим двум точкам сетки.

Перенесите проверку на окна VC-SGC: задайте знак сопряжённого поля, переведите средние составы в производную, интегрируйте, оцените влияние шага и размера ячейки. Пересэмплируйте временные блоки окон через весь анализ. Для атомистического сравнения зафиксируйте потенциал, T/P, разрешённые фазы, химические перестановки, смещения и механические степени свободы. Укажите, откуда берётся общая константа свободной энергии между ветвями.

**Контроль.** Можете объяснить, почему исчезновение разрешимой двухфазной области на одной сетке ещё не определяет критическую температуру, и какие дополнительные данные изменят вывод.

## 9. Самостоятельный разбор

Выберите случай из [проектных практикумов](../methods/projects/README.md). Для шлаков проследите единицу концентрации и состав чистого эталона. Для символьной регрессии проверьте, какую область формула исключает уже до алгебраического сокращения. Для GFA разберите время жизни мотива, который ещё существовал в последнем кадре. Для QHA отделите тепловое расширение от температурного изменения кривизны. Каждый случай имеет собственные входы и локальную проверку.

Итоговый запрос: «Проведи зачёт по выбранному методу. Дай мне маленький новый вход и одну правдоподобную ошибку. До моего ответа не раскрывай ошибку. Затем сверим числа со скриптом, назовём ограничения примера и данные для переноса на реальную систему». Лучший итог занятия — файл результата, который другой человек может повторить по команде, входам и указанному критерию.
