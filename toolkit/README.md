## Локальный старт

Для чтения и просмотра кода достаточно клона коллекции. Утилиты используют Python 3.10+ и стандартную библиотеку. Чтобы проверить целостность комплекта из корня репозитория, выполните `python toolkit/tools/verify.py`.

При установке навыка путь к клону записывается в `collection-root.txt` рядом с его `SKILL.md`. Можно также задать переменную `MYSKILLS_ROOT`. При работе прямо в клоне каталог `skills/имя/` находится на два уровня ниже корня. При переносе клона обновите путь установкой из нового расположения.

Если предстоит работа с UMT и собственного профиля проекта ещё нет, выполните `python toolkit/tools/setup.py --project "/path/to/project"` из корня клона. Укажите SSH-логин, Slurm-account, проверенные пути home и scratch, путь к своему SSH-ключу. Для уже проверенного локального файла OpenSSH можно добавить `--known-hosts-file "/path/to/known_hosts"`. Все персональные значения записываются в `.mlip/config.json` только в выбранном проекте. Для локального разбора методов профиль не требуется.

## Применение исторических рецептов

Снимки зафиксировали версии, форматы, алгоритмы и диагностику конкретных экспериментов. Параметры из старого задания, включая раздел Slurm, ресурсы, набор данных и checkpoint, требуют выбора для текущего проекта. Поля `@LOCAL_TIAL@`, `@LOCAL_MLIP@`, `@REMOTE_WORK@` обозначают пути, предоставленные владельцем текущего расчёта. Оригинальные репозитории, данные, веса, лицензированные VASP/PAW и научные пакеты для вычислений поставляются отдельно.

Перед каждой новой серией UMT уточните выбранный пользователем аккаунт, если в текущем запросе он ещё не указан. Сопоставьте выбор с SSH-логином и ассоциацией Slurm. Сохранённый профиль сам по себе не выбирает аккаунт для очередной серии.

**Текущая политика DPA4.** Установите `DP_TRITON_INFER=2` **во время** `dp --pt freeze`. Для проверенного режима float32 установите `DP_TF32_INFER=0` и `DP_AMP_INFER=0`. Сверьте энергию, силы и напряжения с исходным checkpoint на тех же конфигурациях, запишите допуски, версии и хеши. В повторных оценках, фононах и MD загрузите именно принятый `.pt2`. Собственный путь LAMMPS проверьте отдельно. `.pt` применяется для обучения, рестарта и явной референсной диагностики. При неудаче экспорта или сравнения исследуйте причину. В исторических снимках встречаются eager inference и Triton 0. [Политика развёртывания](../skills/mlip-deployment/SKILL.md)

## Задание для самопроверки

> Разбери на бумаге один расчёт вязкости. Начни с состава, массы атомов и объёма ячейки, покажи преобразование плотности в г/см³ и единицы для интеграла Грина — Кубо. Опиши подготовку объёма в NPT и независимых реплик в NVT. Выбери подходящий исходник в recipes/TiAl. Отдели вывод из теста сериализации модели от вывода о сходимости вязкости. Объясни, по какому диагностическому графику придётся увеличить траекторию. Остановись до обращения к кластеру.
