# Локальный профиль нового проекта

Для изучения методов откройте клон MySkills в Codex. После пользовательской установки сами навыки находятся в каталоге навыков, а общие рецепты, главы и окружения — в клоне коллекции. Инструкция по установке находится в корневом README.

## Настройка профиля для UMT

1. Установите Python 3.10+ и OpenSSH. Получите свои права доступа, SSH-логин, ассоциацию Slurm, рабочие пути и ограничения на ресурсы. Для каждой новой серии выберите аккаунт с пользователем.
2. Из корня MySkills выполните следующую команду, заменив путь на каталог исследовательского проекта.

   ~~~text
   python toolkit/tools/setup.py --project "/path/to/project"
   ~~~

3. В проекте появится каталог `.mlip/`. Он содержит профиль `config.json`, инструменты, документацию, описания окружений, шаблоны и исторические рецепты. Выберите `partitions.cpu` и `partitions.gpu` по правам вашего логина. Поле `gpu_gres` требуется для GPU, `qos` можно оставить пустым, если кластер назначает подходящий QoS автоматически. В `software` укажите только необходимые пути к активаторам.
4. Подготовьте доверенный `.mlip/known_hosts` по инструкции [SSH и хранилище](01-cluster.md) или укажите заранее проверенный файл через `--known-hosts-file`. Закрытый ключ остаётся на вашей машине. Выполните из проекта `python .mlip/tools/cluster.py doctor`. Значение false обозначает отсутствующую зависимость. Для удалённой диагностики предусмотрена отдельная команда `doctor --remote`.
5. После проверки политик кластера и бюджета подготовьте по [примеру Slurm](03-slurm.md) короткую проверку записи с compute-узла. В проекте сохраняйте хеши входных файлов, выбранный профиль, время, ID задания и результат научной проверки.

Для автоматической локальной настройки перечислите все шесть значений явно. Пример использует условные данные. Такой вызов создаёт профиль, даже если ключ ещё не создан на этой машине.

~~~text
python toolkit/tools/setup.py --non-interactive --project "./my-project" --user LOGIN --account SLURM_ACCOUNT --remote-home /path/to/home --remote-scratch /path/to/scratch --identity-file "./my-key"
~~~

Существующий каталог `.mlip` защищён от перезаписи. Для существующей настройки в рабочем проекте сначала прочитайте её текущий профиль. Можно взять отдельные методы и рецепты прямо из коллекции. [Карта рецептов](12-source-map.md)
