# Сопоставление термодинамических моделей

Эти программы дополняют [четыре основных занятия](../README.md). Они отвечают на разные вопросы о рассчитанной фазовой границе.

## Проверка CALPHAD

[calphad.py](calphad.py) получает TDB пользователя для термодинамического описания Liang и соавторов. Скрипт сравнивает расчёт с десятью выбранными фазами и расчёт на подмножестве HCP_A3/ALTI3_D019. Число фаз и имена жёстко связаны с этой параметризацией. Для другой базы проверьте каждое имя, возможные упорядоченные фазы и её область составов. Дополнительная зависимость — `pycalphad`, входной TDB поставляется пользователем отдельно. [Описание набора](https://doi.org/10.1007/s11669-024-01124-9).

```text
python -m pip install pycalphad
python comparison/calphad.py user_database.tdb calphad_run --temperatures 900 1000 --pressure 101325
```

Для заданных T и P состав равновесной пары определяется по составам фаз с ненулевыми долями. Внутри двухфазной области изменение суммарного состава меняет их доли. Проверьте в CSV число внутренних точек, поддержавших одинаковую пару составов, а в metadata.json — давление, набор фаз, версии ПО и SHA-256 базы. При сопоставлении с решёточным гамильтонианом полезнее всего проверить совпадение ансамбля, ограничения родительской решётки и наличия конкурирующих фаз.

## MBAR и конечный размер

[resampled_mbar.py](resampled_mbar.py) переоценивает относительные веса состояний (k, Q) для повторных выборок связанных окон при одной температуре. k — число атомов Al, Q — координата порядка. Каждая строка массива `specs` задаёт поле Δμ в эВ, жёсткость зонта в эВ и центр Q₀. Здесь энергия зонта равна K(Q−Q₀)²/2 на ячейку. В первой строке `hist` лежат частоты состояний первого окна, в следующих — остальных окон в том же порядке. Сохраняйте сетку состояний и связность перекрытия при перестроении гистограммы. `offset` задаёт смещения логарифмической нормировки окон. В промышленном расчёте начните со смещений, найденных на полной выборке. Нормируйте возвращаемые логарифмические веса с помощью logsumexp.

```text
python comparison/resampled_mbar.py
```

Учебный запуск выдаёт аналитические вероятности 0,2, 0,5 и 0,3 для двух перекрывающихся окон трёхсостоянийной системы. При оценке фазовой границы выбирайте блоки длиннее характерного времени состава и порядка, повторно подгоняйте смещения MBAR, применяйте один разделитель фаз и сохраняйте долю пригодных повторов. На больших ячейках проверяйте наличие переходов между упорядоченными вариантами и перекрытие по обеим координатам.

[size_limit.py](size_limit.py) получает три JSON с оценками максимума для разных N. Сравниваются модели линейной зависимости от 1/N на всех размерах и на двух наибольших, а также чувствительность к N⁻²ᐟ³. Формат каждого входа содержит положительное целое `N`, словарь `central` с полями `T_K`, `x_atpct`, `jump_Q`, `latent_meV_atom`, `profile.lower_barrier` и массив `replicates` из как минимум 16 блоковых оценок с полем `T_K`. Поле барьера — в kBT. Программа возвращает интерсепты по моделям и условные квантили повторов. Сопоставьте их со сменой разделителя, формы ячейки и начальных состояний.

```text
python comparison/size_limit.py small.json medium.json large.json --out size_limit.json
```

## Какие ECI сдвинули составы фаз?

[eci_attribution.py](eci_attribution.py) сравнивает две совместимые сетки из `fit_eci.py` при опорном объёме и одной температуре. Обе должны иметь устойчивую внутреннюю касательную на Ti-богатой ГПУ-ветви. Скрипт строит J(λ) между исходным и конечным наборами, заново решает условия общей касательной и равновесия подрешёток, вычисляет производные составов по 18 неаффинным ECI и интегрирует вдоль пути. Константа и точечный член при фиксированном объёме сдвигают энергию на аффинную по c величину и поэтому сохраняют составы сосуществования.

```text
python comparison/eci_attribution.py fit_a/grid.npz fit_b/grid.npz --temperature 1000 --out contributions.csv
```

Вклад записан в процентных пунктах состава для каждой границы. Сумма вкладов должна совпадать с независимо вычисленным сдвигом. Программа проверяет эту сумму и чувствительность к увеличению числа узлов квадратуры с 8 до 16. При исчезновении различимых фаз на пути процедуру нужно пересмотреть. Суммы для отдельных орбит зависят от выбранного пути в пространстве коэффициентов.

## Проверки и перенос

Код адаптирован из исторических программ TiAl `calphad/liang.py`, `solvus_closure/analysis/resampled_mbar.py`, `solvus_closure/size_limit.py` и `eci_boundary/mfa/attribute.py`. Численные данные проекта передаются через аргументы CLI. Ветки MBAR, экстраполяции по размеру и атрибуции используют NumPy и SciPy из общего файла зависимостей. При сборке проверены точные синтетические вероятности MBAR, три экстраполяции по локальным историческим сводкам размеров и атрибуция при малом изменении одного ECI исторической подгонки. CALPHAD-пересчёт с внешней TDB при упаковке не выполнялся.

**Задание Codex.** «Для моих двух моделей проверь соответствие состава, объёма, температур и фаз. Сопоставь сдвиг границы из суммы вкладов ECI с полной новой касательной. Объясни, какие части интервала неопределённости даёт пересэмплирование MBAR и какие зависят от размеров и фазовых ограничений».
