# От структуры сплава до фазового равновесия

Четыре занятия связывают атомные конфигурации с измеримой величиной — составами двух сосуществующих фаз. Исторический пример проекта TiAl касается раствора α и упорядоченного Ti₃Al (D0₁₉) на общей ГПУ-решётке. Программы сохраняют принятую в нём нумерацию узлов, типы Ti = 0, Al = 1 и геометрию 20 кластерных орбит. Учебный набор данных создаётся локально и описывает модельный сплав.

## Начните с одного запуска

Откройте корень клонированного репозитория в Codex. В терминале перейдите в каталог занятия. Для Python используйте отдельное окружение с Python 3.11 или 3.12. Пары минимальных версий библиотек в `requirements.txt` задают зависимости. Практикум проверен с Python 3.11, NumPy 2.4.6 и SciPy 1.17.1.

```text
cd methods/alloys
python -m pip install -r requirements.txt
python practice.py --example-dir example
```

Скрипт проверяет геометрию и подгонку, гармонический спектр, среднее поле, общую касательную и термодинамическое интегрирование. Каждая проверка останавливает выполнение при выходе за допуск. В каталоге `example` появятся `grid.npz` и `coeff.txt` с нулевыми взаимодействиями. Для повторения используйте новое имя каталога или запустите `python practice.py` для проверки без записи.

|---|---|
| Ранг 20, контроль из 20 ячеек, RMSE порядка 10⁻¹⁶ эВ/атом | Процедура возвращает известные коэффициенты из точно сгенерированных меток. Для физического потенциала ошибку определяют отдельные контрольные расчёты. |

## 1. Какие декорации нужны для определения ECI?

У бинарного сплава на фиксированной решётке каждой идеальной декорации соответствует вектор корреляций X. В этом базисе энергия на атом равна X·J. Константа в строке X равна 1/2, точечный вклад — средней величине спина (−1 для Ti, +1 для Al). Для пары или тройки суммируйте произведения спинов всех переведённых кластеров данной орбиты и делите на число атомов. В маленькой периодической ячейке два кластера могут попасть на одни и те же индексы. Их кратность сохраняется.

Откройте [перечисление орбит](atomistic/hcp_orbits.py) и [скрипт отбора](atomistic/atat/select_cells.py). На чистом Al строка признаков совпадает с вектором кратностей. На смеси две базальные равносторонние тройки 222 различают по проекции центра треугольника на соседний слой. Программа связывает столбцы ATAT с геометрией каждой орбиты.

Для нативного расчёта установите ATAT с утилитами `genstr` и `corrdump` в PATH. Скрипт рассчитан на Bash, `sha256sum`, `tar` и формат ATAT 3.52. Из `methods/alloys` выполните команды в Bash, Linux или WSL.

```bash
bash atomistic/atat/enumerate.sh enumeration
python atomistic/atat/select_cells.py enumeration/enum.tar.gz design
```

Первая команда использует [lat.in](atomistic/atat/lat.in), перечисляет ячейки до 12 узлов и сохраняет общую геометрию и строки корреляций. Вторая сравнивает их с независимым подсчётом, выбирает Ti-богатые ячейки с учётом допустимой фононной суперячейки и замораживает выборку до расчёта энергий. Изучите `design/design.json` (ранг, число обусловленности, ошибка двух вычислений признаков), `design/design.csv` (состав, раздел, признаки), `design/jobs.csv` (объёмы, повторения, сетки). Стандартный путь выбирает 39 обучающих и 7 контрольных конфигураций. Флаг `--fixed` рассчитан на шесть отдельно подготовленных больших ячеек в историческом протоколе.

**Задание Codex.** «Покажи на одном смешанном примере, как вклад пары переходит из `corrdump` в X·J. Найди, почему перестановка орбит 222 может пройти тесты на обеих чистых фазах. Проверь на случайной декорации». Критерий освоения — вы можете восстановить порядок столбцов из геометрии и объяснить, почему без полного ранга некоторые J неразличимы.

## 2. Как получить температурно-зависимое кластерное разложение?

Сохраните идеальную декорацию для корреляций. При заданном объёме релаксируйте атомы, удерживая химические занятия, форму и объём. Рассчитайте статическую энергию, силы в невозмущённой суперячейке и после малых смещений. Вычитание исходных сил, условие акустической суммы, веса q-точек и деление на число атомов задают воспроизводимую фононную метку. В гармонической квантовой формуле энергия кванта при частоте ν в ТГц равна hν. Мнимая внутренняя мода исключает конфигурацию из гармонического приближения на этом объёме.

Для выполнения [разметки](atomistic/label_cell.py) нужны ваш проверенный Ti–Al MTP, серийный MLIP 2 или 3 (`mlp`) и, для фононов, пакет `phonopy`. Нижеследующая строка — диагностический запуск для идеального Ti₃Al. Для количественного результата проверьте сходимость по размеру суперячейки, q-сетке и смещению, оцените область применимости потенциала. Укажите свои файлы модели и исполняемый файл на PATH.

```text
python -m pip install phonopy
python atomistic/label_cell.py --model model.mtp --mlp mlp --mlip-version 3 --prototype Ti3Al_D019 --supercell 2 2 2 --mesh 8 --output example_label
```

На выходе появляются идеальный и релаксированный CFG, исходные силы, сохранённая сетка, файл `label.json` и для устойчивой ячейки `vibrations.csv`. Изучите `model_sha256`, `fmax_eV_A`, `stable_mesh` и `minimum_internal_THz`. При работе по таблице `design/jobs.csv` передайте `--cell` из столбца `cell`, `--ratio` и размеры сеток из этой же строки, а в качестве `--output` задайте `labels/<label_subdir>`. Для пути `--cell` присоедините относительный путь к каталогу `design`. Повторите процедуру для всех строк выбранного объёма.

```text
python atomistic/fit_eci.py design labels fitted --ratios 1
python atomistic/atat/export_eci.py design fitted/grid.npz native --temperature 1000 --corrdump corrdump
```

На каждом объёме [подгонка](atomistic/fit_eci.py) применяет общий фильтр устойчивости к статическим и колебательным меткам. Файл `fitted/validation.json` показывает LOO и ошибку на контроле. `fitted/grid.npz` содержит J для статики и колебаний в порядке `orbit_names`. При экспорте в нативном порядке ATAT используется J/2 для двух узлов примитивной ячейки. [Экспорт](atomistic/atat/export_eci.py) сравнивает предсказания обычным умножением матриц и, при наличии `--corrdump`, внешним расчётом. Для квазигармоники нужны несколько объёмов вокруг минимума и сходимость положения минимума при их добавлении.

**Задание Codex.** «Измени одну внутреннюю частоту в тесте, проследи судьбу метки и покажи маску подгонки. Объясни, почему постоянный и точечный J нельзя опустить при минимизации по объёму». Критерий освоения — вы способны проследить число от конкретной декорации до ошибки свободной энергии на отложенной структуре.

## 3. Как перейти от гамильтониана к бинодали?

В [приближении среднего поля](thermo/mfa.py) для D0₁₉ одна подрешётка имеет заполнение q, три остальные — r, а c = (q + 3r)/4. Для каждого состава ищется минимум однородной свободной энергии по упорядочению. Реализация ориентирована на Ti-богатую ветвь с одной обогащённой подрешёткой и просматривает c от 0 до 0,35. Бинодаль определяется опорной прямой, касающейся однородных ветвей в двух составах. Запустите команду на выданной практикумом идеальной сетке.

```text
python thermo/mfa.py example/grid.npz example/mfa --temperatures 800 --models HA
```

Для идеального раствора кривая выпукла. В `grid_mfa_contacts.csv` ожидается строка `unresolved`; в `grid_mfa_free_energy.csv` записана сама кривая. На термической сетке с несколькими объёмами программа также поддерживает `--models QHA`. Проверьте, приходится ли минимум каждой фазы на край доступного интервала объёмов.

В [монте-карловском решателе](mc/vcs.cpp) за один sweep выполняются N одноузельных предложений. Энергия окна равна H − NΔμ₀c + NkBTκ(c − c₀)². Вычислите изменение всей квадратичной добавки при одном перевороте и восстановите поле по измеренному среднему составу окна. Решатель сверяет инкрементальную энергию с полным пересчётом, а [проверка семплера](mc/check_sampler.py) сравнивает распределения с точными средними для конечной ячейки. Нужен компилятор C++11 или новее.

```bash
c++ -O2 -std=c++11 mc/vcs.cpp -o vcs
python mc/check_sampler.py ./vcs
./vcs mc/static/motifs.txt example/coeff.txt 4 4 3 800 .14 20 0 200 1200 1 801 random ideal 0 example/w1.csv
./vcs mc/static/motifs.txt example/coeff.txt 4 4 3 800 .16 20 0 200 1200 1 802 random ideal 0 example/w2.csv
./vcs mc/static/motifs.txt example/coeff.txt 4 4 3 800 .18 20 0 200 1200 1 803 random ideal 0 example/w3.csv
./vcs mc/static/motifs.txt example/coeff.txt 4 4 3 800 .20 20 0 200 1200 1 804 random ideal 0 example/w4.csv
python thermo/vcsgc.py example/w1.csv example/w2.csv example/w3.csv example/w4.csv --out example/windows --bootstrap 20 --blocks 10
```

В Windows из Developer PowerShell для Visual Studio компиляция выполняется командой `cl /O2 /EHsc /std:c++14 mc/vcs.cpp /Fe:vcs.exe`. Используйте `.\vcs.exe` для запуска и `python mc/check_sampler.py .\vcs.exe` для проверки. Аргументы после файлов задают nx, ny, nz, температуру (K), c₀, κ, Δμ₀ (эВ), длину приработки и производства (sweeps), интервал сохранения, seed, начальное состояние, имя модели, шаг по объёму (Å³/атом) и выходной CSV.

В `window_means.csv` сравните c₀ со средним измеренным составом. В `mc_contacts.json` смотрите отдельно на касательные из интегрирования Δμ, связность гистограмм WHAM, краевые касания и долю bootstrap-повторов с внутренней парой. Короткие траектории идеального сплава способны дать случайные грани выпуклой оболочки по редким гистограммным отсчётам. Удлините окна и проверьте их устойчивость. Для реальных границ требуются независимые старты, временные блоки длиннее корреляционного времени состава и порядка, несколько размеров ячейки и достаточное покрытие по составу.

**Задание Codex.** «Сопоставь идеальные результаты MFA, интегрирования и WHAM. По какому файлу определить, какую пару контактов поддерживает статистика, как оценить неопределённость?». Критерий освоения — вы умеете отличить устойчивую связь двух фаз от шума или границы окна.

## 4. Как проверить кластерный результат атомистическими свободными энергиями?

При фиксированных N, числе атомов Al, T и форме ячейки самыми простыми объектами для проверки служат малые наборы декораций. В ячейке 2×2×1 для двух атомов Al [точное перечисление](alloy_ti/decorations.py) даёт 4 D0₁₉, 12 межслоевых и 12 базальных вариантов. Для декораций со свободными энергиями всей ячейки Fᵢ и кратностями dᵢ общий результат равен −kBT ln Σ dᵢ exp(−Fᵢ/kBT). Кратность входит один раз. Используйте тепловую сетку с согласованной температурой, объёмом и именами орбит.

```text
python alloy_ti/decorations.py --grid example/grid.npz --temperature 800 --output example/decorations.json
```

Для нулевых взаимодействий вероятности групп равны 4/28, 12/28 и 12/28. Выполнение даёт −0,02871471676 эВ/атом. Проверьте формулой −kBT ln(28)/8 и объясните отличие от термодинамического предела идеальной энтропии смешения.

[Атомистический пилот](alloy_ti/pilot.py) использует MLIP 3 с вашим Ti–Al MTP. Он фиксирует центр смещений, проектирует три трансляции, сравнивает два шага оценки гессиана и использует гармонический гауссовский ансамбль как опору. Для каждой декорации при одинаковых координатах измеряется разность энергий реальной и опорной систем. Интеграл по λ проверяется одноступенчатым взвешиванием и отдельными репликами. На новой машине сначала оцените стоимость на минимальном числе смещений. Значение `--model-sha256` возьмите из проверенной записи для вашей модели, а `--out` задайте новым каталогом.

```text
python alloy_ti/pilot.py --help
```

Для интерпретации нужны `ess_min`, `max_weight_endpoint`, вероятность пребывания в выбранной области смещений, чувствительность к ширине предложения и вклад редких близких пар. Один сильно доминирующий кадр делает согласие двух оценок на одной выборке ненадёжным. Для стресс-свободного сольвуса нужны свободные энергии двух независимо релаксирующихся фаз, их общая нормировка и равенство полуграндовых потенциалов. Контролируйте химический порядок, ядерную статистику, давление, форму ячейки и конечный размер. Пример с восемью узлами даёт проверку статистической суммы на фиксированном составе.

**Задание Codex.** «Сравни точную групповую вероятность с оценкой одной декорации. Увеличь жёсткость учебного осциллятора и объясни, как меняются перекрытие ансамблей, эффективный размер выборки и ошибка TI». Критерий освоения — вы можете назвать известную опору, физический ансамбль и тест обратимости для своей задачи.

## Происхождение и границы проверки

Исходные реализации построены в проекте TiAl, в историческом дереве `phase_reproduction/{atomistic,thermo,mc,alloy_ti}`. В этой коллекции пути к моделям, эталонная контрольная сумма и выход атомистического пилота передаются параметрами. Численные данные рукописи, рассчитанные коэффициенты, архивы траекторий и сам MTP остаются входами соответствующего исследования. Для переноса на другой сплав заново задайте решётку, орбиты, химические типы, механические ограничения и область фаз.

При сборке коллекции практикум прошёл численные проверки. C++-решатель собран в Windows и проверен сравнением средних с точным решением, затем построены четыре идеальных окна и обработаны интегрированием и WHAM. По сохранённому историческому выводу ATAT проверен отбор конфигураций, по архивным фононным меткам — новая подгонка и алгебраическое чтение экспортированных ECI. Генерация собственно ATAT на новой машине, пересчёт EFS в MLIP и получение фононов требуют соответствующего внешнего ПО и модели.

Для продолжения откройте руководства [atat-eci](../../skills/atat-eci/SKILL.md), [hcp-thermodynamic-ce](../../skills/hcp-thermodynamic-ce/SKILL.md), [vcsgc-binodal](../../skills/vcsgc-binodal/SKILL.md) и [alloy-free-energy](../../skills/alloy-free-energy/SKILL.md).

Следующее занятие — [сопоставление с CALPHAD, пересэмплирование MBAR, конечный размер и вклад отдельных ECI](comparison/README.md).
